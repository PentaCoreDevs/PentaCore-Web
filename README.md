# PentaCore &lt;;&gt; | Web Corporativa

Sitio web de presentación corporativa de alto impacto para **PentaCore**, desarrollado con enfoque en rendimiento extremo (< 18 KB gzipped total), estética visual distintiva de estudio de ingeniería de software (*tactile & creative technical studio*) y soporte nativo de **tema claro (predeterminado) y modo oscuro alternable**.

![Logo PentaCore](assets/logo-full.svg)

---

## Identidad y Diseño

* **Logo**: `<;>` (símbolo de código limpio, moderno y conciso).
* **Dual-Theme (Claro / Oscuro)**:
  * **Tema Claro (Por Defecto)**: Base cálida y táctil en `#F7F5F0` (*Off White* oficial), tarjetas blancas con bordes de alta definición, textos en azul marino profundo (*Deep Navy* `#162436`) y acentos en *Electric Blue* (`#1F62E6`) y *Mint/Aqua* (`#0D9E84`).
  * **Tema Oscuro**: Modo nocturno de alta precisión con fondos oscuros profundos y contrastes luminosos.
  * **Conmutador interactivo**: Botón en la cabecera que permite alternar temas instantáneamente y guarda la preferencia en `localStorage`.
* **Tipografía Distintiva**:
  * **Syne**: Títulos y cabeceras de alto impacto visual con diseño geométrico editorial.
  * **Plus Jakarta Sans**: Cuerpos de texto y navegación de máxima legibilidad.
  * **JetBrains Mono**: Datos técnicos, métricas del sistema y etiquetas de arquitectura.

---

## Secciones y Componentes

1. **Header / Navegación**:
   * Logotipo depurado `<;> PentaCore` (sin etiquetas ni añadidos innecesarios).
   * Enlaces directos a las secciones.
   * Conmutador de tema Claro / Oscuro.
   * Botón de acción principal *"Hablemos"* y menú móvil responsivo.

2. **Hero Section e Ingeniería Adaptativa (`#arquitectura`)**:
   * Mensaje central de ingeniería: *"Creamos tecnología para resolver problemas reales. Diseñamos y construimos software a medida, aplicaciones y ecosistemas digitales adaptados a tu operación."*
   * **Explorador Interactivo de Arquitectura**: Permite examinar distintas topologías de sistemas y niveles de madurez (*Base Ágil*, *Ecosistema Conectado* y *Alta Escala*) con arquitectura visual y métricas técnicas en tiempo real.

3. **ADN y Manifiesto (`#nosotros`)**:
   * Posicionamiento y filosofía central: *"No creemos que las empresas deban adaptarse al software. Hacemos que el software se adapte a las empresas."*
   * 4 etapas de valor: Diagnóstico, Inteligencia, Ingeniería y Evolución Continua.

4. **Soluciones y Capacidades (`#soluciones`)**:
   * Software a Medida, Plataformas y Productos Digitales, Arquitectura Cloud y DevOps, Automatización y Datos, Consultoría Técnica y Capacitación.

5. **Valores Fundamentales (`#valores`)**:
   * Innovación, Inteligencia, Cercanía, Excelencia y Evolución.

6. **Equipo (`#equipo`)**:
   * Presentación del equipo de ingeniería de PentaCore (**Ana Lucía Grillo**, **Camilo Lemos**, **Fabián Sanchez** y **Leonardo Cerquera**).

7. **Contacto (`#contacto`)**:
   * Canal directo `pentacoredev@gmail.com`, tiempo de respuesta técnica en menos de 24 horas y formulario validado en tiempo real.

8. **Footer**:
   * Mapa de navegación, enlaces de servicios y derechos reservados.

## Comandos de Desarrollo

```bash
# Instalar dependencias
npm install

# Servidor de desarrollo con recarga instantánea
npm run dev

# Compilar para producción (carpeta dist/)
npm run build

# Previsualizar la versión compilada
npm run preview
```
